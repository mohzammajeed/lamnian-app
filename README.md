# Lamnian (Android app + website)

The Lamnian community website packaged as a real Android app with [Capacitor](https://capacitorjs.com). No Kotlin or Java needed: the app is the same HTML/JS site running in a native Android shell. GitHub builds the APK for you.

## Get the APK (no computer setup)
1. Create a GitHub repository and upload **everything in this folder** (keep the `.github` folder; it is hidden on some systems).
2. Open the repo's **Actions** tab. The *Build Android APK* workflow starts automatically on every push (about 5–8 minutes). You can also run it with **Run workflow**.
3. When it finishes, open the run and download **Lamnian-apk** at the bottom. Unzip it and install `Lamnian.apk` on an Android phone (allow "install unknown apps").
4. Optional: publish a GitHub **Release** and the APK is attached to it with a permanent download link.

## Folder layout
| Path | Purpose |
|---|---|
| `www/` | The site and app code (`index.html` is everything; edit this) |
| `capacitor.config.json` | App id `com.lamnian.app`, name, plugins |
| `assets/` | App icon and splash source images (replace with your own PNGs, same names) |
| `keystore/lamnian.jks` | Signing key so every build has the same signature |
| `.github/workflows/build-apk.yml` | Builds the APK in the cloud |
| `api/weather.js`, `vercel.json` | Backend pieces from the website (weather has CORS added for the app) |
| `firestore.rules` | Latest rules (likes, reports, profiles). **Publish them in the Firebase console** (Firestore → Rules) |
| `google-services.json` | Firebase Android config for Google sign-in |

The `android/` project is generated by the workflow, so it is not stored in the repo.

## Settings (`CFG` block in `www/index.html`)
Same as the website, plus **`siteUrl`**, already set to `https://lamnian.vercel.app`. The app uses your private weather API, shares that link when posts are shared, and shows the admin link for the admin account. If you empty it the app still works: weather comes straight from Open-Meteo.

## Sign-in inside the app
- **Email and password** works with no extra setup.
- **Google sign-in** needs one extra step because Google blocks popups inside apps:
  1. Firebase console → Project settings → *Your apps* → **Add app → Android**. Package name `com.lamnian.app`.
  2. Add the signing certificate **SHA-1** and **SHA-256** printed in the *Align and sign APK* step of the workflow log (also listed below).
  3. Download **google-services.json** again (it must contain an Android OAuth client, `"client_type": 1`), replace the one in the repo root, and push. The workflow detects the file and switches Google sign-in on. A `google-services.json` is already included; if the build log shows the warning about a missing Android OAuth client, repeat steps 2–3.

  Signing certificate of the committed key:
  - SHA-1 `7A:B1:A9:F6:B5:72:42:BC:60:39:63:8B:E8:30:26:8F:5A:95:E8:52`
  - SHA-256 `66:09:3B:E4:48:09:9B:BD:2E:79:92:A3:E8:82:4D:D9:66:3C:13:BB:49:BC:0E:CC:CA:39:E8:3E:27:25:E4:9C`
- If sign-in fails with a key/referrer error, check Google Cloud → Credentials → the Firebase browser key. If it has website restrictions, add `localhost`, because the app runs from `https://localhost` internally.

## Website (Vercel)
Still works: `vercel.json` serves the `www/` folder and `api/weather.js` as before. Deploy the same repo to Vercel if you want the website too.

## Important notes
- **Keystore:** `keystore/lamnian.jks` (password `lamnian-app`) is committed for convenience. It is fine for sideloaded APKs. For Google Play, create your own private keystore and store it as a GitHub secret instead, then change the signing step.
- The app needs internet for Firebase scripts, posts and weather. Last-seen posts and weather are cached for offline viewing, as on the website.
- Build tools: Node 22, JDK 21, Capacitor 8 (set in the workflow).

## Build on your own computer (optional)
```
npm install --legacy-peer-deps
npx cap add android
npx capacitor-assets generate --android --assetPath assets
npx cap sync android
npx cap open android      # opens Android Studio → Build → Build APK
```
